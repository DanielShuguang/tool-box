## 目的

截图工具配置管理规范，包括快捷键、保存格式、保存路径等配置项。

## 需求

### 需求：快捷键配置
系统必须支持自定义截图快捷键。

#### 场景：查看快捷键设置
- **当** 用户打开应用设置页面或截图工具内的设置面板
- **那么** 系统必须显示当前的快捷键配置
- **并且** 显示全屏截图、区域截图、窗口截图三个快捷键

#### 场景：修改快捷键
- **当** 用户点击快捷键输入框并按下新的快捷键组合
- **那么** 系统必须记录新的快捷键组合
- **并且** 验证快捷键是否与其他功能冲突

#### 场景：快捷键冲突检测
- **当** 用户设置的快捷键与其他功能冲突
- **那么** 系统必须显示冲突提示
- **并且** 禁止使用该快捷键组合

#### 场景：重置快捷键
- **当** 用户点击"重置为默认"按钮
- **那么** 系统必须将快捷键恢复为默认值
- **并且** 全屏截图：`Ctrl+Shift+S`
- **并且** 区域截图：`Ctrl+Shift+A`
- **并且** 窗口截图：`Ctrl+Shift+W`

### 需求：保存格式配置
系统必须支持配置默认保存格式。

#### 场景：设置默认格式
- **当** 用户在设置中选择默认保存格式
- **那么** 系统必须提供 PNG 和 JPG 两个选项
- **并且** 用户选择的格式必须作为默认值

#### 场景：保存时选择格式
- **当** 用户保存截图时
- **那么** 系统必须在保存对话框中显示格式选择
- **并且** 默认选中用户配置的格式

### 需求：保存路径配置
系统必须支持配置默认保存路径。

#### 场景：设置默认路径
- **当** 用户在设置中点击"选择路径"按钮
- **那么** 系统显示文件夹选择对话框
- **并且** 用户选择的路径必须作为默认保存位置

#### 场景：使用默认路径
- **当** 用户保存截图时未手动选择路径
- **那么** 系统必须使用配置的默认路径
- **并且** 如果默认路径不存在，系统必须提示用户

### 需求：自动复制配置
系统必须支持配置是否自动复制截图到剪贴板。

#### 场景：启用自动复制
- **当** 用户在设置中启用"自动复制到剪贴板"
- **那么** 每次截图完成后，系统必须自动将截图复制到剪贴板
- **并且** 显示"已复制"提示

#### 场景：禁用自动复制
- **当** 用户在设置中禁用"自动复制到剪贴板"
- **那么** 截图完成后，系统不会自动复制到剪贴板
- **并且** 用户需要手动点击"复制"按钮

### 需求：编辑器默认属性配置
系统必须支持配置编辑器工具的默认属性。

#### 场景：设置默认颜色
- **当** 用户在设置中调整默认标注颜色
- **那么** 系统必须保存颜色值
- **并且** 编辑器启动时使用该颜色作为默认值

#### 场景：设置默认线宽
- **当** 用户在设置中调整默认线宽
- **那么** 系统必须保存线宽值
- **并且** 编辑器启动时使用该线宽作为默认值

### 需求：配置同步
系统必须确保全局设置和工具内设置保持同步。

#### 场景：全局设置变更
- **当** 用户在应用设置页面修改截图配置
- **那么** 截图工具内的设置必须立即更新
- **并且** 下次使用截图工具时生效

#### 场景：工具内设置变更
- **当** 用户在截图工具内的设置面板修改配置
- **那么** 应用设置页面的截图配置必须立即更新
- **并且** 配置变更立即生效
