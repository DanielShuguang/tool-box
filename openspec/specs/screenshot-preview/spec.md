## 目的

截图预览窗口规范，用于显示截图结果并提供快速操作。

## 需求

### 需求：预览窗口显示
系统必须在截图完成后显示预览窗口。

#### 场景：预览窗口位置
- **当** 截图完成
- **那么** 系统必须在截图区域旁边显示预览窗口
- **并且** 预览窗口不得遮挡截图区域

#### 场景：预览窗口置顶
- **当** 预览窗口显示
- **那么** 预览窗口必须始终显示在其他窗口之上
- **并且** 用户可以切换置顶状态

#### 场景：预览窗口大小
- **当** 预览窗口显示
- **那么** 预览窗口必须显示截图的缩略图
- **并且** 缩略图必须保持原始宽高比

### 需求：预览窗口操作
系统必须在预览窗口中提供快速操作按钮。

#### 场景：编辑操作
- **当** 用户点击预览窗口中的"编辑"按钮
- **那么** 系统打开标注编辑器窗口
- **并且** 编辑器加载当前截图

#### 场景：保存操作
- **当** 用户点击预览窗口中的"保存"按钮
- **那么** 系统显示文件保存对话框
- **并且** 用户可以选择保存路径和格式（PNG/JPG）

#### 场景：复制操作
- **当** 用户点击预览窗口中的"复制"按钮
- **那么** 系统将截图复制到剪贴板
- **并且** 显示"已复制"提示

#### 场景：关闭操作
- **当** 用户点击预览窗口中的"关闭"按钮或按下 `Esc` 键
- **那么** 系统关闭预览窗口
- **并且** 丢弃当前截图（除非已保存）

### 需求：预览窗口拖拽
系统必须支持预览窗口拖拽移动。

#### 场景：拖拽移动
- **当** 用户按住预览窗口标题栏并拖动
- **那么** 预览窗口必须跟随鼠标移动
- **并且** 窗口位置在释放鼠标后保持

### 需求：预览窗口缩放
系统必须支持预览窗口大小调整。

#### 场景：调整窗口大小
- **当** 用户拖动预览窗口边缘或角落
- **那么** 预览窗口必须调整大小
- **并且** 缩略图必须相应缩放以填充窗口
