## 上下文

当前项目是一个基于 Tauri 2.x 的桌面工具箱应用，包含随机选择器、文件搜索、翻译工具等功能模块。项目使用 Vue 3 + TypeScript 前端和 Rust 后端。

用户需要一个集成的截图工具，避免依赖外部软件。截图工具需要支持全屏、区域、窗口三种截图模式，并提供标注编辑功能。

**技术约束**：
- Tauri 2.x 框架
- Vue 3 + TypeScript + Vite
- Rust 后端 + Tokio 异步运行时
- Naive UI 组件库
- UnoCSS 原子化 CSS

## 目标 / 非目标

**目标：**
- 实现全屏、区域、窗口三种截图模式
- 提供预览窗口，支持快速操作（编辑、保存、复制）
- 实现基于 Fabric.js 的标注编辑器，支持画笔、形状、文字、马赛克
- 支持全局快捷键触发（可自定义）
- 支持保存为 PNG/JPG 文件和复制到剪贴板
- 配置项可在应用设置和工具内独立管理

**非目标：**
- 不支持视频录制
- 不支持 GIF 动图截取
- 不支持 OCR 文字识别（后续可扩展）
- 不支持云端存储或分享功能

## 决策

### 1. 屏幕捕获方案：Rust `screenshots` crate

**选择**：使用 `screenshots` crate 实现屏幕捕获

**理由**：
- 跨平台支持（Windows/macOS/Linux）
- 支持多显示器、DPI 缩射
- 活跃维护，API 简洁
- 返回原始图像数据，便于后续处理

**替代方案**：
- `xcap`：功能类似，但文档较少
- 系统命令调用：依赖系统工具，跨平台兼容性差
- Web API (`getDisplayMedia`)：需要用户授权弹窗，体验不佳

### 2. 标注编辑器：Fabric.js

**选择**：使用 Fabric.js 实现标注编辑器

**理由**：
- 内置支持矩形、圆形、箭头、文字等对象
- 画笔功能完善，支持自定义画笔
- 有插件支持马赛克效果
- 文档完善，社区活跃
- 支持 SVG 导出，便于后续扩展

**替代方案**：
- Konva.js：更轻量，但某些高级功能需要自己实现
- 原生 Canvas API：开发成本高，功能实现复杂
- SVG：不适合大量图形叠加的场景

### 3. 窗口架构：混合模式

**选择**：截图选择窗口（全屏透明）+ 预览/编辑窗口（同一窗口）

**理由**：
- 截图选择需要全屏透明窗口，这是独立的
- 预览和编辑可以在同一窗口中完成，减少窗口数量
- 符合用户需求"预览小窗 → 点击编辑进入标注模式"

**替代方案**：
- 单窗口模式：主窗口会被遮挡，截图后需要重新定位
- 多窗口模式：窗口管理复杂，可能有窗口切换的闪烁

### 4. 数据传输：二进制格式

**选择**：截图数据使用二进制传输，避免 Base64 编码

**理由**：
- 减少数据大小（Base64 会增加 33%）
- 传输效率更高
- 内存占用更少

**替代方案**：
- Base64 编码：简单，但数据量大
- 文件路径传输：需要临时文件管理

### 5. 配置管理：双层存储

**选择**：全局设置 + 工具内独立设置

**理由**：
- 全局设置方便统一管理
- 工具内设置方便快速调整
- 两处配置同步更新

**替代方案**：
- 仅全局设置：切换工具需要跳转设置页面
- 仅工具内设置：不方便统一管理

## 风险 / 权衡

### 风险 1：多显示器和 DPI 缩放兼容性

**风险**：不同显示器的 DPI 缩放可能导致截图区域计算错误

**缓解措施**：
- 使用 `screenshots` crate 的 DPI 感知 API
- 在多显示器环境下进行充分测试
- 提供手动调整 DPI 的配置选项

### 风险 2：全局快捷键冲突

**风险**：用户自定义的快捷键可能与其他应用冲突

**缓解措施**：
- 提供快捷键冲突检测
- 默认快捷键选择不常用的组合（如 `Ctrl+Shift+S`）
- 允许用户禁用全局快捷键

### 风险 3：Fabric.js 性能问题

**风险**：大量标注对象可能导致 Canvas 渲染性能下降

**缓解措施**：
- 使用 Canvas 分层渲染
- 限制单次标注的最大对象数量
- 提供"扁平化"功能，将标注合并到图像

### 风险 4：窗口管理复杂性

**风险**：多窗口状态同步可能出现问题

**缓解措施**：
- 使用 Tauri 的事件系统进行窗口间通信
- 定义清晰的窗口状态机
- 添加窗口状态恢复机制

### 权衡：功能完整性 vs 开发成本

**权衡**：完整的标注功能（画笔、形状、文字、马赛克）开发成本较高

**决策**：优先实现核心功能（矩形、箭头、文字），后续迭代添加其他功能
