## 新增需求

### 需求：全屏截图
系统必须支持捕获当前屏幕的完整内容。

#### 场景：触发全屏截图
- **当** 用户按下全局快捷键（默认 `Ctrl+Shift+S`）或点击主窗口的"全屏截图"按钮
- **那么** 系统立即捕获当前屏幕的完整内容
- **并且** 将截图数据传递给预览窗口

#### 场景：多显示器环境
- **当** 用户在多显示器环境下触发全屏截图
- **那么** 系统必须捕获当前活动窗口所在的显示器
- **并且** 在预览窗口中显示对应的截图

### 需求：区域截图
系统必须支持用户通过鼠标框选指定区域进行截图。

#### 场景：触发区域截图
- **当** 用户按下全局快捷键（默认 `Ctrl+Shift+A`）或点击主窗口的"区域截图"按钮
- **那么** 系统显示全屏透明窗口
- **并且** 光标变为十字准星样式

#### 场景：框选截图区域
- **当** 用户在全屏透明窗口中按下鼠标左键并拖动
- **那么** 系统显示矩形选框，实时跟随鼠标移动
- **并且** 选框外的区域显示半透明遮罩

#### 场景：完成区域选择
- **当** 用户释放鼠标左键完成框选
- **那么** 系统捕获选框内的屏幕区域
- **并且** 关闭全屏透明窗口，将截图数据传递给预览窗口

#### 场景：取消区域选择
- **当** 用户按下 `Esc` 键或右键点击
- **那么** 系统取消截图操作
- **并且** 关闭全屏透明窗口

### 需求：窗口截图
系统必须支持自动识别并捕获指定窗口。

#### 场景：触发窗口截图
- **当** 用户按下全局快捷键（默认 `Ctrl+Shift+W`）或点击主窗口的"窗口截图"按钮
- **那么** 系统显示全屏透明窗口
- **并且** 高亮显示鼠标悬停的窗口轮廓

#### 场景：选择窗口
- **当** 用户将鼠标悬停在某个窗口上
- **那么** 系统实时高亮显示该窗口的轮廓
- **并且** 显示窗口标题提示

#### 场景：完成窗口选择
- **当** 用户点击鼠标左键选择窗口
- **那么** 系统捕获该窗口的完整内容
- **并且** 关闭全屏透明窗口，将截图数据传递给预览窗口

### 需求：DPI 缩放支持
系统必须正确处理不同显示器的 DPI 缩放。

#### 场景：高 DPI 显示器截图
- **当** 用户在高 DPI 显示器（缩放比例 > 100%）上截图
- **那么** 系统必须捕获物理像素而非逻辑像素
- **并且** 截图分辨率必须与实际显示分辨率一致

#### 场景：混合 DPI 环境
- **当** 用户在混合 DPI 环境（不同显示器不同缩放比例）下截图
- **那么** 系统必须根据目标显示器的 DPI 设置进行捕获
- **并且** 截图质量不得下降

### 需求：截图数据格式
系统必须以二进制格式传输截图数据。

#### 场景：截图数据传输
- **当** 截图完成
- **那么** 系统必须将截图数据编码为 PNG 格式的二进制数据
- **并且** 通过 Tauri IPC 传递给前端
- **并且** 禁止使用 Base64 编码
